# PRD

## 问题

AI 起草的中文有一种一眼能认出来的腔调：用词端着（"鉴于""具备""显著"），爱加铺垫和总结句，英文术语全译成中文。用 prompt 描述作者的文风，或者塞几段作者的原文作例子，都只能改掉一小部分；描述得越具体，模型越容易走向另一个极端，变成插科打诨。

## 目标

给定一位作者自己写的中文文章，训练一个本地模型：输入一段 AI 写的中文，输出内容和顺序不变、读起来像这位作者写的中文。整个流程要能交给一个 AI agent 独立完成，人只负责划定语料边界和做盲评。

## 用户

- 想让 AI 起草的文字带上自己声音的中文作者。
- 替作者执行这件事的 AI agent：它读 `skills/voice-lora/SKILL.md`，用配置文件描述作者的语料和机器，跑完全流程。

## 需求

1. 不需要人工标注：训练数据从作者原文反向合成。
2. 配置驱动：路径、改写模型的接口、作者称呼、超参都在一个 YAML 里，代码里没有任何人或机器的专有信息。
3. 数据构造可替换：训练、选点、评估、部署对不同的数据构造方法共用。
4. 把调优经验写成代码：checkpoint 选择和"过头"检测由脚本判断，不靠人读数字。
5. 评估分三层：留出段落上的自动指标，真实目标文章上的自动指标，作者本人的盲评。
6. 单张 32GB 显卡能训练，消费级 Mac 能部署（GGUF / LM Studio）。

## 不做

- 不注入知识，不改论点。
- 不发布任何作者的语料或模型权重。
- 不追求全自动：语料边界和盲评必须由人来定。

## 成功标准

- 留出段落上，模型的 P(作者) 明显高于"同一改写模型 + 检索作者原文作例子"的基线。
- 盲评中，模型输出被作者判为本人所写的比例接近作者对自己真原文的识别率。
- 一个没有上下文的 agent 只读 SKILL.md 和配置示例，就能跑完一轮并判断是否达标。

v1 的结果（作者本人博客）：留出段落 P(作者) 0.87（基线 0.33、原文 0.86）；盲评中模型段落被判为本人所写 16/20，真原文 17/20；对基线胜 14/20。
